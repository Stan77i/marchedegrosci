# Rapports du contrôle qualité

Un fichier par passage, jamais modifié après coup (une correction se voit dans le rapport suivant, « réglé ») :

- `AAAA-MM-JJ-HHhMM-<mode>.md` : écrit par `bash tools/controle/lancer.sh <mode>` (heure d’Abidjan = UTC).
- `AAAA-MM-JJ-controle-general.md` : écrit par Claude à la fin de « Lance le contrôle général MGCI » (`../procedures/CONTROLE_GENERAL.md`).

Gabarit : `../modeles/RAPPORT.md`. Le plus récent est copié dans `../DERNIER_RAPPORT.md` ; la liste des passages est dans `../HISTORIQUE.md`.
Pour lire un rapport : « En bref », puis les P0 et P1, puis « Corrections proposées ».
