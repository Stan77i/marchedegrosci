# Rapports des gardiens

Un fichier par passage de la session programmée, tous les 3 jours : `AAAA-MM-JJ.md` (date du passage, heure d'Abidjan).

- Chaque rapport arrive par une PR « Rapport des gardiens du JJ/MM » qui ne contient que ce fichier. Le propriétaire la lit, répond par les numéros à corriger, puis la fusionne.
- Les rapports ne sont jamais modifiés après coup : une correction se voit dans le rapport suivant (« réglé »).
- Le gabarit et la façon de les écrire sont dans `../MISSION-SESSION-PROGRAMMEE.md`, partie 6.
- Pour lire un rapport : « En bref », puis les points rouges, puis « Corrections proposées ».
