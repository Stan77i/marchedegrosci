# Messages prêts à copier (WhatsApp ou SMS)

À envoyer vous-même, un par un, depuis votre téléphone. Remplacez ce qui est entre crochets.

- `[Prénom]` : le prénom de la personne ;
- `[Vous]` : votre prénom ;
- `[VILLE]`, `[PRODUIT 1]`, `[PRODUIT 2]` : vos choix de l'étape 1 ;
- `[LIEN]` : le lien vendeurs ou acheteurs (`LANCER-EN-1-HEURE.md`, étape 3) ;
- `[AIDE]` : votre canal d'aide (numéro WhatsApp, ou « Écrire au Marché de Gros » dans l'application) ;
- `[HORAIRES]` : vos heures de réponse.

Ce qui est vrai aujourd'hui, et que les messages disent :
- c'est un **essai**, fermé, avec une vingtaine de personnes ;
- l'inscription et les annonces sont **gratuites** ;
- le **paiement n'est pas dans l'application** : l'acheteur paie le vendeur directement, à la livraison, après avoir vu la marchandise ;
- le Marché de Gros **ne demande aucun argent** pendant l'essai ; une commission de 3,5 % sur les ventes est **prévue** pour plus tard, quand le paiement sera dans l'application, et rien n'est prélevé aujourd'hui.

Ne jamais écrire : « payé », « paiement garanti », « remboursé », « dernière chance », « places limitées ».

---

## 1. Invitation vendeur

```
Bonjour [Prénom], c'est [Vous].

J'ai créé le Marché de Gros : une application pour vendre et acheter le vivrier en gros, depuis le téléphone.

Avant de l'ouvrir à tout le monde, je fais un essai pendant 4 semaines avec 20 personnes que je connais, à [VILLE], pour [PRODUIT 1] et [PRODUIT 2]. Je voudrais vous avoir comme vendeur.

C'est gratuit. Le paiement n'est pas encore dans l'application : l'acheteur vous paie directement, à la livraison, après avoir vu la marchandise. Le Marché de Gros ne vous demande rien pendant l'essai.

Ce que je vous demande : publier ce que vous avez vraiment, répondre aux acheteurs, et me dire ce qui ne marche pas.

Pour commencer, ouvrez ce lien sur votre téléphone :
[LIEN]

Vous êtes partant ?
```

## 2. Invitation acheteur

```
Bonjour [Prénom], c'est [Vous].

J'ai créé le Marché de Gros : une application pour acheter le vivrier en gros, depuis le téléphone. Vous voyez les offres et les prix, vous discutez le prix par écrit, sans montrer votre numéro.

Je fais un essai pendant 4 semaines avec 20 personnes que je connais, à [VILLE], pour [PRODUIT 1] et [PRODUIT 2]. Des vendeurs ont déjà mis leurs offres. Je voudrais vous avoir comme acheteur.

C'est gratuit. Le paiement n'est pas encore dans l'application : vous payez le vendeur directement, à la livraison, après avoir vu la marchandise.

Ce que je vous demande : chercher ce dont vous avez besoin, proposer vos prix, et me dire ce qui ne marche pas.

Pour commencer, ouvrez ce lien sur votre téléphone :
[LIEN]

Vous êtes partant ?
```

## 3. Après le « oui » (avec le guide court)

```
Merci [Prénom] !

Voici comment faire. Copiez aussi ce message quelque part, il peut servir.
[Coller ici la version courte de GUIDE-PARTICIPANT.md]

Une question : [AIDE], de [HORAIRES].
```

## 4. Rappel à J+3

À envoyer seulement à ceux qui n'ont encore rien publié ni proposé (voir `SUIVI.md`).

```
Bonjour [Prénom], c'est [Vous].

Avez-vous pu ouvrir le Marché de Gros ? Si quelque chose vous a bloqué (installation, compte, annonce), dites-moi où : je vous aide, et ça m'aide à corriger.

Le lien : [LIEN]
```

## 5. Demande d'avis à J+7

```
Bonjour [Prénom], une semaine d'essai déjà. Merci !

Trois questions, répondez comme vous voulez, même en audio :
1. Qu'est-ce qui a marché ?
2. Qu'est-ce qui vous a gêné ou bloqué ?
3. Qu'est-ce qui vous manque pour vendre ou acheter plus ?
```

## 6. Fin de l'essai

```
Bonjour [Prénom],

L'essai du Marché de Gros se termine. Merci d'avoir participé : vos remarques nous ont servi.

Dernière chose : 10 questions, 3 minutes, ici :
[LIEN DU FORMULAIRE]

Votre compte et vos annonces restent. Je vous dis bientôt la suite.
```

## 7. Pause de l'essai (si on doit arrêter)

Seulement si un des cas de `PLAN.md`, partie 9, arrive. Dire la vérité, sans détails techniques.

```
Bonjour [Prénom],

Je mets l'essai du Marché de Gros en pause : [raison en une phrase, par exemple « nous avons vu un problème dans les commandes et nous le corrigeons »].

Ne lancez pas de nouvelle commande dans l'application pour l'instant. Pour une commande en cours, écrivez-moi : [AIDE].

Je vous préviens dès que l'essai reprend.
```
