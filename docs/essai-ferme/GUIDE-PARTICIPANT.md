# Guide du participant

Deux versions : la courte (à coller dans WhatsApp), puis la page complète (à lire ou à expliquer de vive voix).

Chaque bouton cité ici existe dans l'application (relu dans le code le 25/10/2026).

---

## Version courte (10 lignes, à envoyer)

```
1. Ouvrez le lien sur votre téléphone. iPhone : Partager → « Sur l'écran d'accueil ». Android : ⋮ → « Installer l'application ».
2. « Créer mon compte » : prénom, nom, numéro, code secret de 6 chiffres. Notez le code de secours (12 caractères) : il sert si vous oubliez votre code.
3. Publier : « J'ai » pour vendre, « Je cherche » pour acheter. Produit, quantité, prix, ville.
4. Négocier : sur une annonce, « Proposer un prix ». L'autre a 48 h pour répondre. Votre numéro reste caché.
5. Accord conclu : « Suivre la commande » ; dites qui transporte et où livrer. L'autre confirme.
6. Vendeur : « Photographier le colis » (2 à 4 photos, le poids) et glissez le papier du mot secret dans la marchandise.
7. Acheteur : à l'arrivée, vérifiez, puis tapez le mot secret trouvé dans le colis.
8. Un problème ? Vous avez 1 h après la réception pour « Refuser la marchandise » ou « Signaler un problème ».
9. Le paiement se fait entre vous, à la livraison, après avoir vu la marchandise. Rien ne se paie dans l'application.
10. Une question : Messages → « Écrire au Marché de Gros ».
```

---

## 1. Installer

- Ouvrez le lien reçu **sur votre téléphone** (sur ordinateur, une page vous montre un QR code à scanner avec le téléphone).
- **iPhone** : dans Safari, touchez **Partager**, puis **« Sur l'écran d'accueil »**.
- **Android** : dans Chrome, touchez **⋮**, puis **« Installer l'application »** ou **« Ajouter à l'écran d'accueil »**.
- L'icône du Marché de Gros apparaît sur l'écran du téléphone. Ouvrez l'application depuis cette icône.

## 2. S'inscrire

- Touchez **« Créer mon compte »**.
- Remplissez : **prénom**, **nom**, pseudonyme (facultatif), **votre numéro**, un **code secret de 6 chiffres** (deux fois).
- L'application vous montre un **code de secours de 12 caractères**, une seule fois. **Écrivez-le sur un papier** : il permet de choisir un nouveau code si vous oubliez le vôtre.
- Notifications : menu → **Réglages** → **Activer les notifications**. Sur iPhone, ça ne marche qu'après « Sur l'écran d'accueil ».

## 3. Publier

- **« J'ai »** : vous vendez. **« Je cherche »** : vous achetez.
- Choisissez le produit, la quantité, l'unité, le prix et votre ville.
- Vous vendez et achetez **seulement dans la ville de votre annonce**.
- Vos **3 premières annonces sont gratuites sans vérification**. Pour en publier d'autres, faites vérifier votre identité : **Mon compte** (touchez votre photo) → **« S'identifier »** (pièce d'identité et selfie ; l'équipe décide en quelques jours).
- Une annonce reste en ligne 30 jours ; l'application vous prévient 3 jours avant, et vous pouvez la prolonger.

## 4. Négocier

- Sur une annonce, touchez **« Proposer un prix »** : votre prix et la quantité.
- L'autre personne a **48 heures** pour **accepter**, **refuser** ou **contre-proposer**.
- Quand vous êtes d'accord, l'accord est conclu : le prix et la quantité ne bougent plus.
- Vos numéros restent cachés. Pour écrire, touchez **« Écrire »** sur l'annonce. L'équipe peut relire les échanges en cas de litige.

## 5. Commander

- Après l'accord, touchez **« Suivre la commande »**. Dites qui transporte et où livrer. L'autre personne confirme.
- **Même ville** : le vendeur organise son livreur ; l'acheteur paie le livreur directement, hors Marché de Gros.
- Sans commande dans les 72 heures après l'accord, l'accord devient « sans suite » et la marchandise revient sur l'annonce.
- Vous retrouvez vos commandes dans **Mon compte** → **Mes commandes**.

## 6. Vendeur : préparer et charger

- Touchez **« En préparation »**.
- Touchez **« Photographier le colis »** :
  - **2 à 4 photos** du colis emballé ;
  - le **poids pesé** ;
  - le **papier du mot secret** : ayez un papier et un stylo, touchez **« Afficher le code »**, écrivez le mot secret et le code sur le papier (vous avez 3 minutes), puis photographiez-le. Seule l'équipe voit cette photo.
- **Glissez le papier dans la marchandise.** Ne donnez jamais le mot secret par message.
- Touchez **« Chargement confirmé »**, puis **« Le camion est parti »**.
- Vous avez **72 heures** après la confirmation pour charger. Sinon, l'acheteur peut annuler.

## 7. Acheteur : recevoir

- À l'arrivée, touchez **« La marchandise est arrivée »**.
- Vérifiez la quantité et la qualité. Retrouvez le papier du vendeur dans la marchandise.
- Tapez le **mot secret** (5 essais au plus), puis **« Réception confirmée »**.

## 8. Un problème : 1 heure pour le dire

- Après avoir confirmé la réception, vous avez **1 heure** pour réclamer. Sans réclamation, la commande se clôt toute seule.
- Marchandise gâtée, abîmée ou manquante : touchez **« Refuser la marchandise »**, tapez le mot secret et ajoutez des photos (la marchandise et le papier).
- Pas de papier dans le colis, ou autre souci : touchez **« Signaler un problème »** (possible dès que la commande est confirmée).
- Si vous dites « cassé » alors que les photos du départ sont propres, c'est à vous de le prouver. L'équipe du Marché de Gros juge.

## 9. L'argent pendant l'essai

- **Le paiement n'est pas dans l'application.** L'acheteur paie le vendeur directement, à la livraison, après avoir vu la marchandise.
- Ne payez jamais d'avance à une personne qui vous presse.
- Le Marché de Gros ne vous demande aucun argent pendant l'essai. Une commission de 3,5 % sur les ventes est prévue pour plus tard, quand le paiement sera dans l'application. Aujourd'hui, rien n'est prélevé.

## 10. À qui écrire

- Dans l'application : **Messages** → **« Écrire au Marché de Gros »**. Des réponses toutes prêtes s'affichent ; touchez **« Je veux parler à une personne »** pour avoir l'équipe.
- Ou : [AIDE], de [HORAIRES].
- Une annonce louche : touchez **« Signaler cette annonce »**. Un membre louche : écrivez au Marché de Gros.
